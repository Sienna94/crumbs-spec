# 스펙 문서 린트 설정 샘플

crumbs `check`는 문서 구조(필수 절·순서·링크·앵커·근거 경로·정책 중복)만 결정적으로 검사한다. 문체와 표기는 `check`에 넣지 않고, 이 디렉터리의 설정을 스펙 저장소가 복사해 린터로 검사한다. 근거는 `docs/briefs/2026-11-02-읽기-좋은-기술문서-레퍼런스.md`다.

## markdownlint

1. `markdownlint.jsonc`를 저장소 루트에 `.markdownlint.jsonc`로 복사한다.
2. 템플릿 디렉터리는 제외한다. 템플릿의 `<file>`·`<n>` 자리 표시가 MD033(인라인 HTML)에, `#<정책-앵커>`가 MD051에 걸리기 때문이다. markdownlint-cli2는 `.markdownlintignore`를 읽지 않으므로 아래처럼 `#` 글롭으로 빼거나 `.markdownlint-cli2.jsonc`의 `ignores`에 적는다.
3. 실행한다.

```bash
npx markdownlint-cli2 "docs/specs/**/*.md" "#docs/specs/templates"
```

설정의 요점은 파일 안 주석에 있다. `MD013`(줄 길이), `MD022`·`MD032`(제목·목록 앞뒤 빈 줄. crumbs 템플릿은 절 제목 바로 아래 본문을 둔다), `MD043`(필수 절)은 끈다. `MD026`에 `?`를 더해 질문형 제목을 막는다. `MD044.names`는 저장소가 채운다. `MD059`의 금지어는 영어만 둔다. markdownlint 0.42가 링크 텍스트를 `\W` 기준으로 정규화해 한국어를 빈 문자열로 만들기 때문에, 한국어 금지어를 넣으면 모든 한국어 링크가 오탐된다.

## 한국어 스크립트 검출

린터가 없는 한국어 규칙은 정규식으로 근사 검출한다. 지적은 참고일 뿐이고 판정은 사람이 한다.

| 검출 | 정규식 | 근거 |
| --- | --- | --- |
| 문체 혼용 | `(습니다\|입니다)\.`와 `(해요\|어요\|예요)\.`가 한 파일에 같이 있음(crumbs 본문은 `-한다`체) | 한국어 기술 문서 특수 기준 |
| 영문 식별자 뒤 조사 띄어쓰기 | ``[A-Za-z0-9`] (은\|는\|이\|가\|을\|를\|의\|에\|로\|와\|과)`` | 한글 맞춤법 제41항 |
| 쌍점 띄어쓰기 | `[가-힣] :`, `:[가-힣]`(숫자:숫자는 제외) | 문장 부호 해설(2014) |
| '제' 띄어쓰기 | `제 \d` | 행정문서 표현 개선 보고서 |
| 번역투·이중 피동 | `에 의해 .{0,10}(되\|된\|됨)`, `에 있어서`, `(보여\|되어)지` | 공공언어 바로 쓰기, 법제처 정비기준 |
| 미래 서술 | `(곧\|예정\|향후\|추후)` | 현재 시제 원칙 |
| 설명 없는 링크 텍스트 | `\[(여기\|이곳\|링크\|클릭)\]\(` | 원칙 9, MD059의 한국어 대체 |

예:

```bash
grep -rnE '에 의해 .{0,10}(되|된|됨)|에 있어서|(보여|되어)지' docs/specs
```

날짜는 로그 항목과 같은 `YYYY-MM-DD`로 통일하므로 공문서식 날짜(`2022. 12. 31.`) 검출은 두지 않는다.

## hanlint와 Vale

- hanlint: `pip install hanlint` 뒤 `hanlint docs/specs/<파일>.md`로 번역투, 명사 나열, 이중 피동을 잡는다. 지적이 있으면 종료 코드 1을 돌려주므로 CI 게이트로 쓸 수 있다. 2026-08에 만들어진 소규모 개인 저장소이고 의미나 사실은 판정하지 않는다.
- Vale: 외래어 표기와 용어 통일은 substitution 규칙으로 고정한다.

```yaml
# .vale/styles/Terms/Loanwords.yml
extends: substitution
message: "'%s' 대신 '%s'을(를) 쓴다"
level: warning
swap:
  어플리케이션: 애플리케이션
  비지니스: 비즈니스
```

## 하지 않는 것

- 이 설정을 `crumbs init`이 설치하지 않는다. 린터 선택은 저장소의 몫이다.
- 여기 규칙을 `crumbs check`로 올리지 않는다. 문체·내용 판정은 결정적 검사에 넣지 않는다.
